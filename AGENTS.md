# Pink TV
Application Android autonome, paquet ca.pinktv. Interface française rose, menus Télé/Films/Séries/Favoris/Enregistrements, tactile et D-pad.
Les comptes Xtream sont saisis par l’utilisateur et chiffrés avec Android Keystore. Aucun identifiant fournisseur ni clé de signature dans Git ou les livrables.
Aucun PC, jumelage ou serveur compagnon. Favoris/historique par compte et enregistrements sur cet appareil.
Préserver les licences du décodeur audio. Compiler, exécuter les tests et documenter les limites réelles; ne pas prétendre avoir testé un fournisseur ou un Firestick physique sans preuve.
